Limits of this scan

  • Python files get data-flow analysis inside one function. JavaScript and TypeScript get pattern checks only.
  • There is no cross-file data flow and no dependency scanning. Allowlist checks and similar guards are invisible to the static stage; the AI check exists for those cases.
  • AI output is treated as a claim. Its quoted code must exist in the file, line numbers are recomputed, and critical findings are never dismissed automatically.
