What happens to your upload

  • It stays on this computer. Nothing is sent to an online service, and the page loads no outside scripts or fonts.
  • Your code is read, never run. Archives that try to write outside their folder, contain links, or expand to a huge size are refused.
  • The unpacked source is deleted as soon as the scan ends. The report is removed after one hour.
  • Python gets data-flow analysis. JavaScript and TypeScript get pattern checks only.
